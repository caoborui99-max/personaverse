## 必要修复

- 无密钥、空白密钥、缺少模型或地址、总开关关闭均不调用Provider。模型仍从服务器环境读取，不猜测真实ID。
- 输出默认256 Token，上限256，配置超出范围拒绝；可调低。默认请求/响应读取超时20000ms，不跟随重定向、不自动重试。
- 401认证失败 -> AI_AUTH_FAILED；402余额不足 -> AI_BALANCE_INSUFFICIENT；404模型或路径不存在 -> AI_MODEL_UNAVAILABLE。400/422等仍为安全的通用参数/供应商错误，不能只凭状态断言具体模型原因。429/503分别限流/暂不可用。
- 错误正文不透传；若成功响应正文回显实际配置的密钥，也拒绝该响应。API status不返回密钥。兜底日志仅错误类型，CLI不输出环境、正文或错误对象。
- 管理员聊天的DAILY_LIMIT=1、RATE_LIMIT=1固定于服务端；不读取AI_DAILY_LIMIT/AI_RATE_LIMIT放宽限制。前者全站共享、后者每管理员UTC分钟窗口；UTC日窗口。环境变量可以保留为部署说明，但不能改变实际上限。
- 请求claim、并发锁、额度和历史继续使用已有数据库，不新建生产结构。一次已尝试失败保留扣减；同请求不重发，完成请求返回缓存。拒绝请求ID对应不同内容。
- Soul Core不进入组装消息，十二人格设定不改变；新增测试验证两者。

测试时钟仅作为服务端函数依赖注入用于模拟跨日/跨分钟；浏览器请求不接受now字段，环境变量不能注入时钟。多轮测试跨模拟UTC日继续验证历史，未为测试降低生产限制。窗口不是滚动60秒，操作系统时间及可信运维仍是安全假设。

## 风险与回滚

Mock只能验证本地协议和控制逻辑，不代表供应商模型已经可用。401/402/404判别基于HTTP状态，真实供应商可能返回不同状态，未知情况安全失败而不重试。失败/超时仍可能已计费；日额度不是人民币金额承诺。

一次工具的状态标记仅约束同一受保护目录，不是跨机器、防运维删除的全局收费系统；本轮不能运行它发真实请求。日/分钟限额固定为UTC窗口，依赖持久数据库和可信系统时钟，不能用重置数据库绕过。重建空库或更换部署也不算安全重试。

没有生产/schema变更，当前无需数据回滚。未来需要撤销共享提交时用新revert提交；不覆盖54c07d6或本地归档，不重写远程历史。旧代码恢复后其额度可能更宽，回滚前应关闭AI_ENABLED。
