# Phase 4B 就绪检查

结论：**不能开始真实 DeepSeek 接入或上线**。本轮交付的 Fake 费用安全底座通过本地 PostgreSQL 验证，Cloudflare 整体运行仍阻断。未经站长下一阶段批准不接入真实服务。

## 必须先完成

1. 修复 Workers 动态路由编译与 Argon2 WASM 阻断。原强度 PHC 必须可互验，在 workerd 跑完整认证、安全 Cookie、CSRF、退出/改密/过期和资源基准。保持作者原文、版本和 SQL 保护。
2. 在 Workers 跑完整真实 PG 业务事务/约束/锁/回滚/并发/故障回归；随后单独申请云测试资源授权。Hyperdrive 必须禁用敏感查询缓存；实际验证撤销、发布状态、余额不陈旧，配置独立最小权限应用账户。
3. 确认真实 DeepSeek 协议、模型/价格版本、币种、tokenizer、输出硬上限、序列化开销、取消/超时/重试和计费规则。当前字节估算与假价格不是最终价格表。
4. 确认供应商是否支持幂等请求和请求级账单证据。数据库幂等不能保证外部 exactly-once；没有可核验证据的 unknown 必须人工处理并保留预算。建立受控对账权限、追加审计与告警，不能把模拟证据用于真实结算。
5. 审核 dispatch 授权与外部 HTTP 发送之间的窗口，记录发送/接收状态证据，测试 Worker 中断与数据库故障。真实 Provider 必须使用独立的明确启用配置、服务端秘密绑定；默认关闭、预算零、无 Key/配置拒绝。当前代码完全没有真实 Provider。
6. 预算管理必须经授权设置，所有币种和周期都有硬限额。建立恢复/清理调度、熔断报警、预算看板与人工 unknown 对账流程；本轮仅提供本地安全恢复函数/命令，没有云端调度。
7. 可信 Cloudflare IP 获取与 Service Binding 防伪、反刷、隐私保留及密钥轮换需真实验证；匿名 ID/IP 不是可靠真人身份。测试/业务数据库与生产严格隔离。
8. 迁移 0005 遇旧 AI 请求/费用行会主动失败。站长必须先审查真实旧数据与迁移方案，不得自动修正费用或人格原文。备份恢复、最小权限、灾难恢复演练需要后续独立验收。
9. 经站长授权后才可申请资源、设置秘密和运行有限测试调用；不得在本轮完成后自动推进。上线前重新核对官方限制/费用、大陆访问与实际运营预算。

可先审核本地提交、SQL 0005/0006、锁序、未知结果规则及 Cloudflare 最小重构方案。任何真实费用路径仍需专项审查；不能因为本轮 Fake 测试通过直接开启真实 AI。
