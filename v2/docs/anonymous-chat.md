# 聊天模式与身份隔离

数据库模式的匿名访客使用独立 VisitorSession 和 pv_v2_visitor_local（HTTPS 为 \_\_Host-pv_v2_visitor）；管理员始终使用 AdminSession。即使管理员浏览公开页面，公开聊天也按访客 API 独立处理；指定版本测试只通过 /admin/test 命名空间。

数据库聊天持久化到 ChatSession/ChatMessage，绑定固定 coreVersionId，读取记录必须核对所有者。客户端不能传 role、内核或历史。消息 ID 幂等，事务行锁串行化写入，失败回滚释放锁；相同消息 ID 不重复保存，不同内容返回 409。NOWAIT 冲突可重试，事务 10 秒上限；没有真实 provider 调用。

数据库访客有最多 50 个会话、单会话 500 轮模拟消息的容量保护。管理员模拟测试不套用这些访客限制。全站真实费用目前为零；真实 AI 接入前必须增加分布式限流、费用预留与熔断，不能仅靠这些演示容量限制上线收费模型。

/fail-once 仍可验证请求失败后的重试。浏览器先保存待确认消息，刷新时查询服务端历史；若实际已保存则清除待重试状态，否则使用原 ID 重试。Cookie 失效时允许重连并保留输入。清除删除当前访客服务端会话及 pv:v2:chat:\* 本地快照，不改旧版存储或收藏。

PV_MODE=mock-regression 保留第二阶段内存聊天和所有原测试，明确与 PostgreSQL 测试隔离。两种模式都不代表真实 AI。DeepSeek、流式回复、上下文 token 预算、真实费用熔断和生产级全站请求保护尚未实现。
