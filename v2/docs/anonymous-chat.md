# 模拟聊天与未来真实聊天

当前 mock 服务使用随机 HttpOnly pv_v2_mock Cookie 识别访客，固定 24 小时失效；只监听 loopback。所有写请求要求与配置完全相符的 Origin，拒绝跨站 Fetch。访客内存集合隔离会话，ID 不授予权限。

会话由服务器生成 UUID，绑定测试人格；消息由服务器读取已有历史，不接受客户端历史、system prompt 或 role。每个客户端消息有 UUID：相同 ID/内容重发返回现有记录；不同内容返回 409。发送和写入是同步原子步骤，不在临界区 await，因此并发重复消息不会保存两次。

每分钟 120 条 mock 请求、每访客 50 个会话、每会话 500 轮；这不是正式访客每日额度策略。无真实 AI 成本。/fail-once 在首次请求持久化前返回 503，同 ID 重试成功。

UI 用 try/finally 释放请求状态；待重试消息先存本地，刷新可使用相同 ID 重试。服务端已成功但响应丢失时也不会重复写入。超时为 15 秒。服务器重启/访客过期时提示重连并保留输入内容，不伪装成已恢复服务端历史。

清除删除当前 Cookie 所有演示会话及当前设备 pv:v2:chat:\* 快照。收藏不受影响。不修改旧版存储。禁用/损坏 localStorage 时降级并提示；不支持跨设备同步。

## 真实 AI 前置工作（未实现）

PostgreSQL 持久会话与消息、分布式原子额度、请求 lease 与结果未知状态、按 token 构造上下文、DeepSeek 服务端调用、费用预留/结算/熔断、隐私保留与删除策略。内核单独完整加载，不允许请求改写；管理员先由服务端识别后跳过访客额度。聊天和后台响应禁止缓存。
